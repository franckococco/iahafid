1) Bajar el código
------------------
Si ya tenés la carpeta:

git pull origin main

Si es la primera vez:

git clone https://github.com/franckococco/iahafid.git
cd iahafid


2) Copiar el .env a mano
------------------------
El .env NO está en GitHub (tiene el token de WhatsApp y el de Gemini).
Copiá el archivo .env de esta PC a la misma carpeta en la otra.
O copiá TOKEN-LOCAL.txt (está en esta PC, no se sube a GitHub).
Sin eso el bot no habla ni con WhatsApp ni con Gemini.


3) Instalar y levantar (PowerShell, dentro de la carpeta)
---------------------------------------------------------

.\.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
